Server event reference for the Qwen-Audio Realtime API. All server events include the common fields `event_id` (automatically generated by the server) and `type` (event type).

**User guide**: [Real-time voice conversations (Qwen-Audio-Realtime)](https://help.aliyun.com/zh/model-studio/fun-audiochat-realtime). For event interaction sequences, see [WebSocket API](https://help.aliyun.com/zh/model-studio/fun-audiochat-realtime-websocket-api).

## **error**

**Description**: Returned for request errors or service failures. Client errors (`invalid_request_error`) do not interrupt the connection; server errors (`server_error`) terminate it.

| **event\\_id** `*string*` Unique identifier of this event. | ``` { "event_id": "event_xxx", "type": "error", "error": { "type": "invalid_request_error", "code": "invalid_value", "message": "Cannot create response while another response is in progress.", "param": "response.create" } } ``` |
| --- | --- |
| **type** `*string*` Event type, fixed to `error`. |
| **error** `*object*` Error details. **Properties** **type** `*string*` Error type, such as `invalid_request_error` (client error) or `server_error` (server error). **code** `*string*` Error code. **message** `*string*` Error message. **param** `*string*` Parameter associated with the error. |

## **session.created**

**Description**: The first event sent by the server after the connection is established. Contains the default session configuration.

| **event\\_id** `*string*` Unique identifier of this event. | ``` { "event_id": "event_KiKZC2zrhNsKFPZ5cTpyA", "type": "session.created", "session": { "object": "realtime.session", "model": "qwen-audio-3.0-realtime-plus", "modalities": ["text", "audio"], "voice": "longanqian", "input_audio_transcription": { "model": "fun-asr" }, "turn_detection": { "type": "server_vad", "threshold": 0.5, "silence_duration_ms": 800 }, "id": "sess_A1LbG2D63WELBSawRbpq8" } } ``` |
| --- | --- |
| **type** `*string*` Event type, fixed to `session.created`. |
| **session** `*object*` Session configuration. **Properties** **object** `*string*` Fixed to `realtime.session`. **model** `*string*` Model name. **modalities** `*array*` Model output modalities. **voice** `*string*` Voice for model-generated audio: a system voice name or the `voice_id` of a cloned voice. **input\\_audio\\_transcription** `*object*` Audio transcription configuration. **Properties** **model** `*string*` Audio transcription model, such as `fun-asr`. **turn\\_detection** `*object*` Turn detection (VAD) configuration. **id** `*string*` Unique session identifier. |

## **session.updated**

**Description**: Returned after a `session.update` request is processed successfully, containing the complete updated session configuration. On failure, an `error` event is returned instead.

| **event\\_id** `*string*` Unique identifier of this event. | ``` { "event_id": "event_FMG6kiHbILCGiqXFPA98e", "type": "session.updated", "session": { "id": "sess_A1LbG2D63WELBSawRbpq8", "object": "realtime.session", "model": "pre-fun-realtime-audiochat-beta-3", "modalities": ["text", "audio"], "voice": "longanqian", "input_audio_transcription": { "model": "fun-asr" }, "turn_detection": { "type": "smart_turn", "threshold": 0.1, "silence_duration_ms": 900 } } } ``` |

## **conversation.item.ambient\_audio\_transcription.delta**

**Description**: **Smart\_turn mode only.** Incremental ambient audio transcription results. When VAD detects speech activity but semantic analysis deems it an invalid turn (such as noise or non-semantic sounds like "um" or "ah"), ASR results are passed to the client as ambient events. This event is not associated with any item in the conversation context; `item_id` is an independently generated temporary ID.

| **event\\_id** `*string*` Unique identifier of this event. | ``` { "event_id": "event_xxx", "type": "conversation.item.ambient_audio_transcription.delta", "item_id": "item_xxx", "content_index": 0, "text": "嗯", "stash": "" } ``` |
| --- | --- |
| **type** `*string*` Event type, fixed to `conversation.item.ambient_audio_transcription.delta`. |
| **item\\_id** `*string*` Independently generated temporary ID, not associated with any item in the conversation context. |
| **content\\_index** `*integer*` Index of the content part. |
| **text** `*string*` Confirmed transcription text. |
| **stash** `*string*` Tentative text not yet confirmed. |
